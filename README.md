# 노래 분리 믹서

유튜브 링크나 음악 파일을 넣으면 보컬 / 베이스 / 드럼 / 기타 악기로 나누고,
트랙마다 음량을 0~200%로 조절하며 들을 수 있는 앱입니다. 내 컴퓨터에서 돌아갑니다.

## Mac 앱 (StemMixer)
- `mac/` 폴더에 네이티브 Mac 앱이 있어요. 먼저 아래 "실행"대로 한 번 설치(`.venv`)한 뒤
  `mac/build.sh --install` 하면 `/Applications/StemMixer.app` 이 생겨요.
- 앱이 켜질 때 분리 엔진(server.py)을 알아서 띄우고, 앱을 끄면 같이 꺼져요. 터미널·브라우저 필요 없음.
- 앱은 이 폴더의 `.venv` 와 `server.py` 를 쓰니 폴더를 옮기면 `mac/build.sh --install` 을 다시 실행하세요.
- 링크 칸에 유튜브 · 스포티파이 · 애플뮤직 · 사운드클라우드 링크나 그냥 곡 제목을 넣어도 돼요.
  스포티파이/애플뮤직은 음원이 DRM으로 막혀 있어서, 곡 정보(가수·제목·길이)를 읽은 뒤
  유튜브에서 길이가 가장 비슷한 영상을 찾아 받아요. 찾은 영상 제목이 플레이어 위에 표시돼요.
- 노래가 아닌 영상(말하는 영상 · 방송 · 강의)은 나누지 않아요. 라이브 방송과 20분 넘는 영상은 바로 막고,
  유튜브 '음악' 분류가 아니면 10분 넘는 영상도 막아요. 나머지는 받은 뒤 곡 여기저기를 AI(PANNs)로 들어 보고
  말소리 없이 음악이 나오는 곳이 절반도 안 되면 멈춰요 (배경음악만 깔린 짧은 브이로그는 노래로 볼 수 있어요).
  노래가 맞는데 막혔으면 오류 칸의 "노래 맞아요 · 그래도 나누기"를 누르세요 (받은 파일을 다시 써요).
- 이미 분리한 곡을 다른 방식(AI 4트랙 · AI 6트랙 · 빠르게)으로 다시 나누려면 목록에서 곡에 마우스를 올리고 ↻ 버튼
  (또는 오른쪽 클릭 → 다른 방식으로 분리, 플레이어 위의 "다른 방식으로 분리"). 이미 만든 버전이 있으면 그걸 열어요.
  원본 오디오는 `library/_sources/` 에 보관해서 다시 받지 않아요 (곡의 모든 버전을 지우면 같이 지워져요).
- **Space** 재생/정지 (링크 칸에 글을 쓰는 중일 때만 빼고), 키보드의 ⏯ 키·에어팟으로도 돼요. 링크 칸에서 나오려면 esc.
- **트랙을 내 것으로 바꾸기** (예: 원래 보컬 대신 내가 부른 보컬):
  - 오디오 파일(wav, mp3, m4a, aiff…)을 트랙 위에 끌어다 놓거나, 트랙 오른쪽 클릭 → "내 파일로 바꾸기…".
    샘플레이트·채널이 달라도 곡에 맞춰 바꾸고, 곡 길이에 맞게 자르거나 채워요.
  - 오른쪽 클릭 → "여기에 녹음하기": 3초 세고 나서 그 트랙만 끈 채로 곡이 재생되고, 마이크로 녹음해요.
    헤드폰을 끼면 스피커 소리가 안 섞여요. Space로 정지하면 그 자리에 들어가고, esc는 취소.
    스피커·마이크 지연은 자동으로 빼 주고, 남은 차이는 싱크 조절로 맞춰요.
  - 트랙 이름 밑의 "내 녹음" 버튼: 원래 트랙과 번갈아 듣기, 싱크 맞추기(−500 ~ +500ms), 다시 녹음, 지우기.
  - 바꾼 트랙은 곡 폴더의 `user/` 에 저장되고, 재생 · 믹스 저장 · 편집 앱으로 보내기에 그대로 쓰여요.
- **음정 뽑기 (MIDI)**: 트랙 오른쪽 클릭 → "음정 뽑기 (MIDI)" → 소리(피아노 · 신스 리드 · 사인 · 스트링) 고르기.
  그 트랙의 음 높이와 박자를 읽어서 음표로 만들고, 깔끔한 소리로 다시 연주한 "○○ 음정" 트랙이 생겨요.
  - 보컬은 노래 채보 전용 모델 GAME(OpenVPI)으로, 피아노는 피아노 전용 모델(ByteDance)로 음표를 읽어요. 처음 한 번 모델을 받아요.
    베이스는 torchcrepe로 음 높이를 읽고, 기타 · 나머지(화음)는 basic-pitch로 읽어요. 모델을 못 받으면 예전 방식(torchcrepe · basic-pitch)으로 읽어요.
  - "MIDI" 버튼: 소리 바꾸기, 조옮김(반음 · 옥타브), 키에 맞추기, 빠르기(BPM, ½ · ¾ · ×2), MIDI 파일 끌어놓기 · 복사.
  - 피아노 롤에서 음표가 재생 위치에 맞춰 흘러가요.
  - 정확도 (알고 있는 멜로디로 합성해서 잰 note F1, 음 시작 ±50ms): 보컬 멜로디 1.00, 반주가 섞인 보컬 0.98,
    피아노 화음 + 아르페지오 0.95. 4분 곡 기준 보컬 · 베이스 약 30초, 화음 트랙 몇 초.
  - 원래 음색은 남지 않아요 (음정 · 리듬만). 꺾기 · 바이브레이션은 음표로 정리되면서 일부 사라지고,
    빽빽한 화음이나 아주 빠른 연주는 덜 정확해요. 빠르기는 곡에 따라 ¾배 · 2배로 잘못 잡힐 수 있어서 직접 고칠 수 있어요.
- **음표 편집**: 트랙 오른쪽 클릭 → "음표 편집" (음정 트랙이 없으면 "AI로 음정 뽑아서 편집" 또는 "빈 악보로 시작").
  AI가 찍은 음표가 피아노 롤로 열리고, 믹서 자리에서 바로 고칠 수 있어요.
  - 더블클릭: 음표 추가 · 지우기. 끌기: 옮기기 (위아래 = 음 높이). 오른쪽 끝 끌기: 길이. ⌥ 끌기: 복사. 빈 곳 끌기: 여러 개 선택.
  - Delete 지우기, ↑↓ 반음 (⇧ 옥타브), ←→ 격자 한 칸, Q 박자 맞추기, ⌘Z / ⇧⌘Z, ⌘A, ⌘C / ⌘X / ⌘V (재생 위치에), ⌘D 복제, Space 재생.
  - 격자(1/4 · 1/8 · 1/16 · 1/32 · 끄기)는 곡 빠르기 기준. 끄는 중에 ⌘를 누르면 격자를 무시해요. 스크롤로 이동, ⌘ + 스크롤 · 핀치로 확대.
  - "들을 소리": 전체 곡 / 원래 트랙만 / 음표만 / 둘 다. "원래 윤곽"은 처음(AI) 음표를 점선으로 보여 줘요.
  - **음높이 선** (보컬 · 베이스): 원래 목소리가 실제로 부르는 음높이를 10ms마다 읽어서 음표 위에 선으로 그려요.
    음표가 선보다 높거나 낮은 곳을 고치면 돼요. 음정을 뽑을 때 같이 저장되고, 예전 곡은 편집 화면을 처음 열 때 한 번 읽어요.
    트랙을 내 녹음으로 바꿨으면 내 녹음의 음높이를 그려요.
  - **가사**: 음표를 고르고 Return → 가사 입력 칸이 떠요. Return · Tab은 다음 음표, ⇧Tab은 앞 음표, Esc는 닫기.
    "가져오기 · 더보기 → 가사 한꺼번에 넣기…"(또는 오른쪽 클릭)에 가사를 붙여 넣으면 음절마다 차례로 들어가요
    (일본어는 가나 한 글자, きゃ처럼 작은 글자는 앞 글자와 함께 · 한국어는 한 글자 · 영어는 단어 하나).
    넣은 가사는 OpenUtau(.ustx) · UTAU(.ust) · MIDI(가사 이벤트) 내보내기에 들어가고, 이 파일들을 가져올 때도 가사를 읽어요.
  - **AI 가사**: 도구 막대의 "AI 가사"(또는 가져오기 · 더보기 → AI로 가사 받아 적기)를 누르면 Whisper가 노래를 듣고 가사를 받아 적어서
    음표마다 한 음절씩 넣어요. 언어는 자동으로 찾거나 고를 수 있어요. 일본어 한자는 히라가나로 바꿔요(OpenUtau 가수가 읽게).
    한 음절을 여러 음표에 걸쳐 부르면 뒤 음표는 "+"(앞 음절 늘여 부르기), 음절이 더 많으면 긴 음표를 나눠요. ⌘Z로 되돌릴 수 있어요.
    처음 한 번 모델(1.5GB 정도)을 받아요. 노래 가사라서 틀리는 곳이 있으니 음표를 고르고 Return으로 고치세요.
  - "적용해서 듣기"(⌘S)를 누르면 음정 트랙 소리 · MIDI 파일 · OpenUtau 내보내기에 반영돼요. "완료"는 적용하고 닫기.
    고친 뒤에도 "가져오기 · 더보기 → AI가 뽑은 음표로 되돌리기"로 돌아갈 수 있어요.
- **다른 곳에서 만든 음표 가져오기**: MIDI(.mid), OpenUtau(.ustx), UTAU(.ust) 파일을 트랙 위에 끌어다 놓거나
  오른쪽 클릭 → "MIDI · UST 파일 가져오기…". 편집 화면으로 열려서 확인한 뒤 적용해요. 트랙이 여러 개인 MIDI는 고르거나 합칠 수 있고,
  이미 음표가 있으면 바꾸기 / 더하기를 골라요. 파일의 0초 = 곡 0초예요 (어긋나면 ⌘A 하고 끌어서 맞추세요).
- **OpenUtau로 바로 보내기**: 보컬 트랙 오른쪽 클릭 → "OpenUtau로 보내기 (음정 · 가사 자동)…". 음정이 없으면 뽑고, 가사가 없으면 받아 적어서
  저장한 뒤 아래 OpenUtau 프로젝트를 만들어 OpenUtau로 바로 열어요. 가수만 고르면 목소리가 바뀌고, 고칠 곳은 OpenUtau에서 고치면 돼요.
- **보컬 신스로 다시 부르기 (OpenUtau · UTAU)**: 보컬 음정 트랙의 "MIDI" 버튼 → "OpenUtau · UTAU로 내보내기…".
  폴더 하나에 `project.ustx`(OpenUtau), `project.ust`(UTAU), `melody.mid`, `backing.wav`(그 파트만 뺀 반주),
  `guide_vocals.wav`(원래 보컬, 음소거된 참고 트랙)가 생겨요. 프로젝트 0틱 = 곡 0초라서, OpenUtau에서 가수
  (예: 무료 UTAU 음원 重音テト)를 고르고 가사를 넣어 조율한 뒤 처음부터 wav로 내보내 보컬 트랙에 끌어다 놓으면 싱크가 맞아요.
  편집 화면에서 넣은 가사가 들어가고, 가사 없는 음표는 "ら". 한글 가사가 있으면 .ust는 UTF-8로 저장해요. "박자 맞춰서"는 16분음표 격자에 맞춰요 (빠르기가 맞을 때만). 음원은 각 제작사 약관을 따라 주세요.
  OpenUtau Singers 폴더(`~/Library/OpenUtau/Singers`)에 가수가 있으면 (테토가 있으면 테토로) 자동으로 지정해요.
- **편집 앱으로 보내기** (GarageBand, Logic, Ableton, FL Studio 등):
  - 트랙 왼쪽 ≡ 를 끌어서 편집 앱 타임라인이나 Finder에 놓으면 그 트랙 wav가 들어가요 ("곡 제목 - 보컬.wav").
  - "모든 트랙 끌어놓기"를 끌면 트랙이 한 번에 들어가요. "지금 믹스 만들기" → "믹스 끌어놓기"로 들리는 그대로도 보낼 수 있어요.
  - 복사(트랙 위 복사 버튼, 오른쪽 클릭, ⌘C = 지금 믹스)한 파일은 Finder에 ⌘V로 붙여넣을 수 있어요.
    대부분의 편집 앱은 복사·붙여넣기 대신 끌어 놓기로 파일을 받아요.
  - "모든 트랙을 폴더로 저장…"으로 한 폴더에 모아 저장할 수도 있어요.

## 브라우저 버전

## 실행
1. Python 3.10 이상 설치 (https://www.python.org/downloads/ , Windows는 설치 화면에서 "Add Python to PATH" 체크)
2. 이 폴더를 통째로 내려받기
3. Windows: `start-windows.bat` 더블클릭 / Mac: `start-mac.command` 더블클릭
   - Mac에서 열리지 않으면 터미널에서 `chmod +x start-mac.command` 한 번 실행 후 다시 더블클릭.
   - 처음 한 번은 설치 때문에 몇 분 걸립니다 (AI 라이브러리 약 1~2GB).
   - 끝나면 브라우저에 http://localhost:8000 이 자동으로 열려요.

## 쓰는 법
- 링크 칸에 유튜브·스포티파이·애플뮤직 링크나 곡 제목을 넣고 **분리하기**. 화면 아무 데서나 붙여넣어도 들어가요.
- 파일은 점선 칸에 끌어다 놓기.
- **고음질 (AI)**: Demucs가 깔끔하게 분리. CPU에서 곡 길이의 1~2배 시간 (처음 한 번 모델 80MB 다운로드).
  **빠르게 (주파수 필터)**: 몇 초면 끝나지만 소리가 섞임.
- 트랙별 슬라이더로 0~200%, 더블클릭하면 100%로 돌아옴. 끄기 / 솔로 버튼.
- 프리셋: 원곡, 노래방(보컬 끄기), 보컬만, 베이스만, 드럼만, 베이스 연습, 베이스 크게
- **이 설정으로 저장**: 지금 들리는 그대로 wav 파일로 저장.
- 한 번 분리한 곡은 아래 "최근 분리한 곡"에 남아서 다시 기다릴 필요 없어요. 곡마다 슬라이더 설정도 기억해요.
- 단축키: 스페이스 재생/정지, ←/→ 5초, 1 보컬만, 2 베이스만, 3 드럼만, 4 기타만 · 5 피아노만 (6트랙 곡), 0 원곡

## 저장 공간
- ••• 메뉴 → "저장 공간 관리…": 곡마다 차지하는 용량(큰 순서), 여러 곡 골라서 한 번에 지우기.
  "빠르게 고르기"로 이전 방식으로 나눈 곡 · 같은 곡의 옛 버전 · 30일 넘은 곡을 한 번에 고를 수 있어요.
- "정리하기": 끌어놓기용 임시 파일, 지운 곡의 원본, 끝난 작업이 남긴 파일만 지워요 (곡은 그대로).
  분리 중일 때는 진행 중인 작업 파일을 건드리지 않아요.
- 곡 목록에도 곡마다 용량이 보여요. 트랙은 소리 손실 없는 FLAC(24비트)으로 저장해서 6트랙 곡이 4분에 250MB 정도예요.
- "공간 줄이기": 예전에 wav로 저장한 곡의 트랙을 FLAC으로 바꿔요 (실제 6트랙 곡에서 296MB → 184MB, 40% 가까이). 바꾼 파일을 다시 읽어서 샘플이 하나도
  다르지 않을 때만 wav를 지워요. 편집 앱으로 끌어놓기 · 복사 · "트랙 모두 저장"은 그대로 wav로 나가요.

## 유튜브가 안 받아질 때
- 유튜브는 가끔 특정 방식의 다운로드를 막아요 (HTTP 403). 서버가 막히면 다른 방식으로 자동으로 다시 시도해요.
- 그래도 안 되면 `.venv/bin/python scripts/check_youtube.py [링크]` 로 어디서 막히는지 볼 수 있어요.

## 참고
- 분리된 파일은 `library/` 폴더에 쌓입니다. 앱에서 삭제하거나 폴더를 지우면 됩니다.
- 유튜브 다운로드가 갑자기 안 되면 앱을 다시 실행하세요. 실행할 때마다 yt-dlp를 최신으로 업데이트합니다.
- 유튜브 음원은 개인 연습/감상 용도로만 쓰세요.

## 분리 방식과 품질
| 방식 | 하는 일 | 4분 곡 (Apple Silicon) |
|---|---|---|
| **고음질 4트랙** (기본) | BS-Roformer SW로 나누고 → 나머지 악기에 남은 목소리를 MelBand RoFormer로 한 번 더 뽑아 보컬로 → 드럼 · 베이스는 SW와 htdemucs_ft를 섞기 | 약 6~8분 |
| **고음질 6트랙** | 같은 방식 + 기타 · 피아노 (기타에 남은 목소리도 한 번 더 뽑기) | 약 8~10분 |
| **최고 음질** ("최고 음질" 체크) | 고음질 + 보컬을 BS-Roformer revive v2로 한 번 더 뽑아 섞기 (4 · 6트랙 모두) | 약 2배 |
| **빠르게** | Demucs htdemucs만 | 약 20초 |

MUSDB18 테스트 곡 12개로 잰 점수 (SDR, dB, 높을수록 깨끗함)와 보컬을 끈 반주에 남는 목소리 (「ライラック」, 낮을수록 좋음):

| | 보컬 | 드럼 | 베이스 | 나머지 | 평균 | 남은 목소리 |
|---|---|---|---|---|---|---|
| 빠르게 (htdemucs) | 9.13 | 7.95 | 8.04 | 4.50 | 7.41 | — |
| 이전 고음질 (RoFormer 보컬 + Demucs) | 11.98 | 9.44 | 8.67 | 6.06 | 9.04 | −43 dB |
| BS-Roformer SW 단독 | 12.00 | 10.45 | 8.09 | 6.41 | 9.24 | −34 dB |
| 이전 고음질 (SW + 남은 목소리 + 베이스만 htdemucs_ft) | 12.01 | 10.45 | 8.70 | 6.40 | 9.39 | −66 dB |
| **지금 고음질** (드럼 0.85 SW + 0.15 ft, 베이스 0.35 SW + 0.65 ft) | 12.01 | 10.51 | 9.06 | 6.65 | 9.56 | |
| **최고 음질** (보컬 0.4 고음질 + 0.6 revive v2) | **12.79** | **10.57** | **9.06** | **6.85** | **9.82** | |

(6트랙의 기타 · 피아노는 MUSDB에 정답 트랙이 없어서 "나머지"에 합쳐서 쟀어요. 마지막 세 줄은 나머지를
"원곡 − 다른 트랙"으로 세는 새 방식으로 다시 잰 점수예요. 섞는 비율도 이 12곡으로 정해서 다른 곡에서는 조금 덜 좋아질 수 있어요. 나머지 트랙은 원곡에서 다른 트랙을 뺀 소리라서
트랙을 모두 더하면 언제나 원곡 그대로예요.)

예전 "빠르게(주파수 필터)" 방식은 보컬에서 6kHz 이상을 잘라 버려서 먹먹했어요. 지금은 목록에 없고,
그 방식으로 만든 예전 곡은 "다른 방식으로 분리"로 다시 나눌 수 있어요. 트랙은 24비트 FLAC으로 저장해요 (예전 곡은 wav).
보컬 모델(약 900MB)은 처음 고음질로 나눌 때 `models/` 에 한 번 내려받아요.

## 사용 시 주의
- 개인 연습·감상용으로 만든 도구예요. 본인이 권리를 가졌거나 사용 허락을 받은 음원에만 쓰세요.
  분리한 트랙을 다시 배포하거나 상업적으로 쓰면 저작권 침해가 될 수 있어요.
- 유튜브 등에서 음원을 받는 것은 각 서비스의 이용약관을 따르세요.
- YouTube, Spotify, Apple Music, SoundCloud는 각 회사의 상표이며, 이 프로젝트는 그 회사들과 관계가 없어요.

## 배포 방식
- 소스 코드만 배포해요. 미리 빌드된 앱, AI 모델, 라이브러리, 음원은 저장소에 들어 있지 않아요.
- Mac 앱은 위 "실행"으로 한 번 설치한 뒤 `mac/build.sh --install` 로 직접 빌드하세요 (Xcode 또는 Command Line Tools 필요).

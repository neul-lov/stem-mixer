# 노래 분리 믹서

유튜브 링크나 음악 파일을 넣으면 보컬 / 베이스 / 드럼 / 기타 악기로 나누고,
트랙마다 음량을 0~200%로 조절하며 들을 수 있는 앱입니다. 내 컴퓨터에서 돌아갑니다.

## Mac 앱 (StemMixer)
- `mac/` 폴더에 네이티브 Mac 앱이 있어요. 먼저 아래 "실행"대로 한 번 설치(`.venv`)한 뒤
  `mac/build.sh --install` 하면 `/Applications/StemMixer.app` 이 생겨요.
- 앱이 켜질 때 분리 엔진(server.py)을 알아서 띄우고, 앱을 끄면 같이 꺼져요. 터미널·브라우저 필요 없음.
- 앱은 이 폴더의 `.venv` 와 `server.py` 를 쓰니 폴더를 옮기면 `mac/build.sh --install` 을 다시 실행하세요.
- 링크 칸에 유튜브 · 스포티파이 · 애플뮤직 · 사운드클라우드 링크나 그냥 곡 제목을 넣어도 돼요.
  스포티파이/애플뮤직은 음원이 DRM으로 막혀 있어서, 곡 정보(가수·제목·길이)를 읽은 뒤
  유튜브에서 길이가 가장 비슷한 영상을 찾아 받아요. 찾은 영상 제목이 플레이어 위에 표시돼요.

## 브라우저 버전

## 실행
1. Python 3.10 이상 설치 (https://www.python.org/downloads/ , Windows는 설치 화면에서 "Add Python to PATH" 체크)
2. 이 폴더를 통째로 내려받기
3. Windows: `start-windows.bat` 더블클릭 / Mac: `start-mac.command` 더블클릭
   - Mac에서 열리지 않으면 터미널에서 `chmod +x start-mac.command` 한 번 실행 후 다시 더블클릭.
   - 처음 한 번은 설치 때문에 몇 분 걸립니다 (AI 라이브러리 약 1~2GB).
   - 끝나면 브라우저에 http://localhost:8000 이 자동으로 열려요.

## 쓰는 법
- 링크 칸에 유튜브·스포티파이·애플뮤직 링크나 곡 제목을 넣고 **분리하기**. 화면 아무 데서나 붙여넣어도 들어가요.
- 파일은 점선 칸에 끌어다 놓기.
- **고음질 (AI)**: Demucs가 깔끔하게 분리. CPU에서 곡 길이의 1~2배 시간 (처음 한 번 모델 80MB 다운로드).
  **빠르게 (주파수 필터)**: 몇 초면 끝나지만 소리가 섞임.
- 트랙별 슬라이더로 0~200%, 더블클릭하면 100%로 돌아옴. 끄기 / 솔로 버튼.
- 프리셋: 원곡, 노래방(보컬 끄기), 보컬만, 베이스만, 드럼만, 베이스 연습, 베이스 크게
- **이 설정으로 저장**: 지금 들리는 그대로 wav 파일로 저장.
- 한 번 분리한 곡은 아래 "최근 분리한 곡"에 남아서 다시 기다릴 필요 없어요. 곡마다 슬라이더 설정도 기억해요.
- 단축키: 스페이스 재생/정지, ←/→ 5초, 1 보컬만, 2 베이스만, 3 드럼만, 0 원곡

## 참고
- 분리된 파일은 `library/` 폴더에 쌓입니다. 앱에서 삭제하거나 폴더를 지우면 됩니다.
- 유튜브 다운로드가 갑자기 안 되면 앱을 다시 실행하세요. 실행할 때마다 yt-dlp를 최신으로 업데이트합니다.
- 유튜브 음원은 개인 연습/감상 용도로만 쓰세요.

## 사용 시 주의
- 개인 연습·감상용으로 만든 도구예요. 본인이 권리를 가졌거나 사용 허락을 받은 음원에만 쓰세요.
  분리한 트랙을 다시 배포하거나 상업적으로 쓰면 저작권 침해가 될 수 있어요.
- 유튜브 등에서 음원을 받는 것은 각 서비스의 이용약관을 따르세요.
- YouTube, Spotify, Apple Music, SoundCloud는 각 회사의 상표이며, 이 프로젝트는 그 회사들과 관계가 없어요.

## 배포 방식
- 소스 코드만 배포해요. 미리 빌드된 앱, AI 모델, 라이브러리, 음원은 저장소에 들어 있지 않아요.
- Mac 앱은 위 "실행"으로 한 번 설치한 뒤 `mac/build.sh --install` 로 직접 빌드하세요 (Xcode 또는 Command Line Tools 필요).

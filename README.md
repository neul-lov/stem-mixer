# 노래 분리 믹서

유튜브 링크나 음악 파일을 넣으면 보컬 / 베이스 / 드럼 / 기타 악기로 나누고,
트랙마다 음량을 0~200%로 조절하며 들을 수 있는 앱입니다. 내 컴퓨터에서 돌아갑니다.

## Mac 앱 (StemMixer)
- `mac/` 폴더에 네이티브 Mac 앱이 있어요. 먼저 아래 "실행"대로 한 번 설치(`.venv`)한 뒤
  `mac/build.sh --install` 하면 `/Applications/StemMixer.app` 이 생겨요.
- 앱이 켜질 때 분리 엔진(server.py)을 알아서 띄우고, 앱을 끄면 같이 꺼져요. 터미널·브라우저 필요 없음.
- 앱은 이 폴더의 `.venv` 와 `server.py` 를 쓰니 폴더를 옮기면 `mac/build.sh --install` 을 다시 실행하세요.
- 링크 칸에 유튜브 · 스포티파이 · 애플뮤직 · 사운드클라우드 링크나 그냥 곡 제목을 넣어도 돼요.
  스포티파이/애플뮤직은 음원이 DRM으로 막혀 있어서, 곡 정보(가수·제목·길이)를 읽은 뒤
  유튜브에서 길이가 가장 비슷한 영상을 찾아 받아요. 찾은 영상 제목이 플레이어 위에 표시돼요.
- 이미 분리한 곡을 다른 방식(AI 4트랙 · AI 6트랙 · 빠르게)으로 다시 나누려면 목록에서 곡에 마우스를 올리고 ↻ 버튼
  (또는 오른쪽 클릭 → 다른 방식으로 분리, 플레이어 위의 "다른 방식으로 분리"). 이미 만든 버전이 있으면 그걸 열어요.
  원본 오디오는 `library/_sources/` 에 보관해서 다시 받지 않아요 (곡의 모든 버전을 지우면 같이 지워져요).
- **Space** 재생/정지 (링크 칸에 글을 쓰는 중일 때만 빼고), 키보드의 ⏯ 키·에어팟으로도 돼요. 링크 칸에서 나오려면 esc.
- **트랙을 내 것으로 바꾸기** (예: 원래 보컬 대신 내가 부른 보컬):
  - 오디오 파일(wav, mp3, m4a, aiff…)을 트랙 위에 끌어다 놓거나, 트랙 오른쪽 클릭 → "내 파일로 바꾸기…".
    샘플레이트·채널이 달라도 곡에 맞춰 바꾸고, 곡 길이에 맞게 자르거나 채워요.
  - 오른쪽 클릭 → "여기에 녹음하기": 3초 세고 나서 그 트랙만 끈 채로 곡이 재생되고, 마이크로 녹음해요.
    헤드폰을 끼면 스피커 소리가 안 섞여요. Space로 정지하면 그 자리에 들어가고, esc는 취소.
    스피커·마이크 지연은 자동으로 빼 주고, 남은 차이는 싱크 조절로 맞춰요.
  - 트랙 이름 밑의 "내 녹음" 버튼: 원래 트랙과 번갈아 듣기, 싱크 맞추기(−500 ~ +500ms), 다시 녹음, 지우기.
  - 바꾼 트랙은 곡 폴더의 `user/` 에 저장되고, 재생 · 믹스 저장 · 편집 앱으로 보내기에 그대로 쓰여요.
- **편집 앱으로 보내기** (GarageBand, Logic, Ableton, FL Studio 등):
  - 트랙 왼쪽 ≡ 를 끌어서 편집 앱 타임라인이나 Finder에 놓으면 그 트랙 wav가 들어가요 ("곡 제목 - 보컬.wav").
  - "모든 트랙 끌어놓기"를 끌면 트랙이 한 번에 들어가요. "지금 믹스 만들기" → "믹스 끌어놓기"로 들리는 그대로도 보낼 수 있어요.
  - 복사(트랙 위 복사 버튼, 오른쪽 클릭, ⌘C = 지금 믹스)한 파일은 Finder에 ⌘V로 붙여넣을 수 있어요.
    대부분의 편집 앱은 복사·붙여넣기 대신 끌어 놓기로 파일을 받아요.
  - "모든 트랙을 폴더로 저장…"으로 한 폴더에 모아 저장할 수도 있어요.

## 브라우저 버전

## 실행
1. Python 3.10 이상 설치 (https://www.python.org/downloads/ , Windows는 설치 화면에서 "Add Python to PATH" 체크)
2. 이 폴더를 통째로 내려받기
3. Windows: `start-windows.bat` 더블클릭 / Mac: `start-mac.command` 더블클릭
   - Mac에서 열리지 않으면 터미널에서 `chmod +x start-mac.command` 한 번 실행 후 다시 더블클릭.
   - 처음 한 번은 설치 때문에 몇 분 걸립니다 (AI 라이브러리 약 1~2GB).
   - 끝나면 브라우저에 http://localhost:8000 이 자동으로 열려요.

## 쓰는 법
- 링크 칸에 유튜브·스포티파이·애플뮤직 링크나 곡 제목을 넣고 **분리하기**. 화면 아무 데서나 붙여넣어도 들어가요.
- 파일은 점선 칸에 끌어다 놓기.
- **고음질 (AI)**: Demucs가 깔끔하게 분리. CPU에서 곡 길이의 1~2배 시간 (처음 한 번 모델 80MB 다운로드).
  **빠르게 (주파수 필터)**: 몇 초면 끝나지만 소리가 섞임.
- 트랙별 슬라이더로 0~200%, 더블클릭하면 100%로 돌아옴. 끄기 / 솔로 버튼.
- 프리셋: 원곡, 노래방(보컬 끄기), 보컬만, 베이스만, 드럼만, 베이스 연습, 베이스 크게
- **이 설정으로 저장**: 지금 들리는 그대로 wav 파일로 저장.
- 한 번 분리한 곡은 아래 "최근 분리한 곡"에 남아서 다시 기다릴 필요 없어요. 곡마다 슬라이더 설정도 기억해요.
- 단축키: 스페이스 재생/정지, ←/→ 5초, 1 보컬만, 2 베이스만, 3 드럼만, 0 원곡

## 참고
- 분리된 파일은 `library/` 폴더에 쌓입니다. 앱에서 삭제하거나 폴더를 지우면 됩니다.
- 유튜브 다운로드가 갑자기 안 되면 앱을 다시 실행하세요. 실행할 때마다 yt-dlp를 최신으로 업데이트합니다.
- 유튜브 음원은 개인 연습/감상 용도로만 쓰세요.

## 분리 방식과 품질
| 방식 | 하는 일 | 4분 곡 (Apple Silicon) |
|---|---|---|
| **고음질 4트랙** (기본) | 보컬은 MelBand RoFormer, 반주에서 드럼은 htdemucs_6s · 베이스는 htdemucs_ft, 나머지는 남은 소리 전부 | 약 3분 |
| **고음질 6트랙** | 같은 방식 + 기타 · 피아노는 htdemucs_6s | 약 3분 |
| **빠르게** | Demucs htdemucs만 | 약 20초 |

모델마다 잘하는 악기가 달라서(드럼은 htdemucs_6s, 베이스는 htdemucs_ft) 악기별로 가장 좋은 쪽을 가져와요.
"나머지 악기"는 반주에서 다른 트랙을 뺀 소리라서, 트랙을 전부 더하면 원곡과 같아요.

MUSDB18 테스트 곡 12개로 잰 점수 (SDR, dB, 높을수록 깨끗함):

| | 보컬 | 드럼 | 베이스 | 나머지 | 평균 |
|---|---|---|---|---|---|
| 빠르게 (htdemucs) | 9.13 | 7.95 | 8.04 | 4.50 | 7.41 |
| 이전 6트랙 (htdemucs_6s) | 9.36 | 8.58 | 7.03 | 4.22 | 7.30 |
| **고음질 4트랙 · 6트랙** | **12.02** | **9.33** | **8.66** | **6.02** | **9.01** |

(6트랙의 기타 · 피아노는 MUSDB에 정답 트랙이 없어서 "나머지"에 합쳐서 쟀어요.)

예전 "빠르게(주파수 필터)" 방식은 보컬에서 6kHz 이상을 잘라 버려서 먹먹했어요. 지금은 목록에 없고,
그 방식으로 만든 예전 곡은 "다른 방식으로 분리"로 다시 나눌 수 있어요. 트랙은 24비트 wav로 저장해요.
보컬 모델(약 900MB)은 처음 고음질로 나눌 때 `models/` 에 한 번 내려받아요.

## 사용 시 주의
- 개인 연습·감상용으로 만든 도구예요. 본인이 권리를 가졌거나 사용 허락을 받은 음원에만 쓰세요.
  분리한 트랙을 다시 배포하거나 상업적으로 쓰면 저작권 침해가 될 수 있어요.
- 유튜브 등에서 음원을 받는 것은 각 서비스의 이용약관을 따르세요.
- YouTube, Spotify, Apple Music, SoundCloud는 각 회사의 상표이며, 이 프로젝트는 그 회사들과 관계가 없어요.

## 배포 방식
- 소스 코드만 배포해요. 미리 빌드된 앱, AI 모델, 라이브러리, 음원은 저장소에 들어 있지 않아요.
- Mac 앱은 위 "실행"으로 한 번 설치한 뒤 `mac/build.sh --install` 로 직접 빌드하세요 (Xcode 또는 Command Line Tools 필요).
